# Portfolio – Raphaël Beduneau

Site statique (HTML / CSS / JavaScript) prêt pour GitHub Pages.

## Publier sur GitHub Pages
1. Créer un dépôt public nommé `raphael-beduneau.github.io`.
2. Y déposer `index.html`, `style.css`, `script.js` et le dossier `assets/`.
3. Dans Settings > Pages, choisir la branche `main` et le dossier `/ (root)`.
4. Le site sera disponible sur https://raphael-beduneau.github.io
